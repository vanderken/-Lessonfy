# About Lessonfy

Lessonfy is a personalized study reader that helps students focus while reading, mark confusing parts, and come back to them later.

## Problem
Many students, especially those with ADHD or attention difficulties, lose focus when reading course material. Most reading tools look the same for everyone and give no way to mark and revisit confusing parts.

## Users
- Students who study on their own
- Students with ADHD or attention difficulties
- Students who struggle to stay focused while reading

## Features
- Register and login
- Create lessons manually (title, subtitle, panels) or by upload with auto-split
- Reading tools: bionic reading, font size, line spacing, focus mode, background sound
- Pin highlighted text to collections with colors
- Dashboard with lesson list, search and a pin summary report

## Stack
- Frontend: React js
- Storage and backend: Springboot

## Setup
1. Clone the repo: `git clone https://github.com/vanderken/-Lessonfy.git`
2. Go into the folder: `cd Lessonfy`
3. Copy `.env.example` to `.env`
4. Install packages: `npm install`
5. Start the app: `npm run dev`
